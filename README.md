# R Code for "Projected distributional shifts and compositional reassembly of freshwater fish thermal guilds under climate change"

This repository contains R scripts supporting the analyses presented in the manuscript entitled "Projected distributional shifts and compositional reassembly of freshwater fish thermal guilds under climate change."

The scripts cover data collection and preprocessing, thermal guild classification, species distribution modelling, guild–environment relationships, distributional changes and spatial overlap, and spatial cluster–direction classification and compositional reassembly.

AI assistance was used to review, correct, and refine the original author-developed R scripts to improve code organization, clarity, readability, and documentation. The analytical framework and scientific interpretations remain the responsibility of the authors.

The scripts are organized by analytical stage to facilitate transparency and reproducibility. Users should provide the required input datasets and adjust file paths and settings as necessary. Figure-generation routines are not included.
